
# PASSGUARD - Password Strength Checker

A simple password strength checker built with HTML, CSS and JavaScript.

## Features

- Check password strength
- Show and hide password
- Check password length
- Check uppercase and lowercase letters
- Check numbers and special characters
- Display Weak, Medium or Strong result

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Enter a password to check its strength.
5. link is in the discription

## Note

The password is checked in your browser.
This project does not save or send passwords to a server.
